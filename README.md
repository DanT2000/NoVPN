# NoVPN

**NoVPN** — простая самостоятельно размещаемая панель управления VPN-доступами.
Заводите VPN-серверы, и панель по SSH сама устанавливает на них ПО (Xray / AmneziaWG,
при желании HTTP/SOCKS5/HTTPS-прокси), выпускает пользователям конфигурации и считает
трафик. Каждый пользователь получает личную ссылку и, для Xray, одну ссылку-подписку
на все устройства.

- Одна панель (Docker-контейнер) = API + веб-интерфейс, база — SQLite на томе.
- Вход администратора — по паролю (отдельного логина нет).
- Пользователь входит по личной ссылке `/k/<токен>` (код — опционально).

---

## Requirements

- Linux-сервер для панели с установленным **Docker** и **Docker Compose v2**
  (`docker compose`). Хватает 1 CPU / 512 МБ RAM.
- Домен, указывающий на этот сервер (для HTTPS панели — обычно через обратный
  прокси: Traefik, Nginx Proxy Manager, Caddy или Coolify).
- Отдельный **VPN-сервер** (Ubuntu/Debian, root по SSH) — на него панель установит
  VPN-ПО. Это не тот же сервер, что панель.

## Installation

```bash
git clone https://github.com/DanT2000/0VPN.git novpn && cd novpn
cp .env.example .env      # при желании впишите PUBLIC_URL и пароль администратора
./install.sh
```

`install.sh` проверит Docker, сам сгенерирует недостающие секреты
(`ENCRYPTION_KEY`, `SESSION_SECRET`) в `.env`, соберёт образ, поднимет панель и
дождётся готовности. По умолчанию панель слушает порт **3000** — направьте на него
ваш обратный прокси с TLS для домена.

## Configuration

Минимум, что задаётся в `.env`:

| Переменная       | Обязательна   | Что это                                                              |
|------------------|---------------|---------------------------------------------------------------------|
| `ENCRYPTION_KEY` | да            | Ключ шифрования секретов в БД. `install.sh` создаст сам. Не менять после старта. |
| `SESSION_SECRET` | да            | Подпись сессий входа. `install.sh` создаст сам.                      |
| `PUBLIC_URL`     | желательно    | **Публичный адрес панели** — базовый URL для ссылок пользователям.   |
| `ADMIN_PASSWORD` | нет (`admin`) | Стартовый пароль администратора. Сменить после первого входа.       |

Остальные параметры — с разумными умолчаниями, см. комментарии в
[`.env.example`](.env.example).

**Публичный адрес панели (`PUBLIC_URL`).** Адрес, по которому пользователи открывают
панель, например `https://panel.example.com`. От него автоматически строятся все
внешние ссылки: личные ссылки пользователей (`/k/…`) и ссылки-подписки Xray (`/sub/…`).
Тот же адрес можно задать/поменять прямо в панели: **Настройки → Адрес сайта**;
значение из панели имеет приоритет над `PUBLIC_URL`. После смены адреса все выданные
ссылки автоматически используют новый адрес — вручную править ничего не нужно.

## First start

1. Откройте панель по вашему адресу (или `http://СЕРВЕР:3000`, если ещё без прокси).
2. Войдите паролем администратора (по умолчанию `admin`) и **сразу смените его**:
   Настройки → Доступ в панель.
3. Задайте адрес сайта: Настройки → Адрес сайта.
4. Добавьте VPN-сервер: Серверы → добавить (host, SSH-доступ, нужные протоколы),
   затем «Установить / переустановить ПО» — панель поставит Xray/AmneziaWG по SSH.
5. Создайте пользователя и отправьте ему личную ссылку.

## Update

```bash
cd novpn && git pull && ./install.sh
```

База лежит на Docker-томе `novpn_data` и переживает пересборку. Миграции применяются
автоматически при старте (только добавление столбцов — данные сохраняются).

## Backup / Restore

- **Backup:** Настройки → «Скачать резервную копию». Скачается зашифрованный паролем
  файл `*.novpnbak` со всей базой (пользователи, серверы, ключи, настройки). Пароль
  храните отдельно — без него восстановить нельзя.
- **Restore:** Настройки → «Восстановить из копии» → выберите файл и введите пароль.
  Панель заменит базу содержимым копии и перезапустится (сделайте свежий backup перед
  восстановлением).

## Troubleshooting

- **Панель не открывается / `install.sh` не дождался healthz** — логи:
  `docker compose -f deploy/docker-compose.yml logs --tail=50 manager`.
- **Красное предупреждение «база не изолирована»** — база не на постоянном томе и
  будет стёрта при обновлении. Убедитесь, что каталог базы примонтирован как том
  (`novpn_data:/data`).
- **Личные/подписочные ссылки с неверным адресом** — задайте адрес в Настройки →
  Адрес сайта (или `PUBLIC_URL`) и перезапустите панель.
- **HTTPS-прокси не ставится** — нужен домен (не IP), указывающий на VPN-сервер, и
  свободный порт 80 на время выпуска сертификата.

## Разработка

Монорепо npm workspaces. Требуется Node.js ≥ 20.

```bash
npm install
npm run dev        # manager (API, :3000) + web (Vite, :5173) параллельно
npm run typecheck  # проверка типов
npm test           # тесты
npm run build      # прод-сборка
```

| Путь | Назначение |
|------|------------|
| `apps/web` | Веб-интерфейс (SPA), пользовательская и админ-части |
| `apps/manager` | Backend / control plane, JSON API, отдача фронтенда, SQLite |
| `packages/shared` | Общие TypeScript-типы и контракты API |
| `deploy/` | Dockerfile и docker-compose |

Продукт в интерфейсе называется **NoVPN**.
