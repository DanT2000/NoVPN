# Скриншоты для README и статьи

Здесь лежат картинки, на которые ссылаются `README.md`, `README.en.md` и `press/habr-ru.md`.
Файлы **не закоммичены** — снимите их сами (так они будут актуальны вашему брендингу и
данным). Ниже — точный список и как снять чисто, без реальных пользователей в кадре.

## Как снять чистые скриншоты (демо-данные, без прода)

Веб-интерфейс умеет работать на **mock-данных** — без backend и без реальной базы. Идеально
для скриншотов: красивые демо-серверы/пользователи, ничего личного.

```bash
npm install
VITE_USE_MOCK=true npm run dev --workspace @novpn/web
# откройте http://localhost:5173  (админка: http://localhost:5173/admin)
```

Снимайте окно браузера (лучше в светлой и тёмной теме — интерфейс поддерживает обе).
Рекомендуемая ширина кадра — 1280–1440 px, retina/2x для чёткости.

## Нужные файлы

| Файл | Что на нём | Где открыть (mock) |
|------|------------|--------------------|
| `dashboard.png` | Обзор: карточки метрик + «Трафик по серверам» | `/admin` → Обзор |
| `cabinet.png` | Личный кабинет пользователя, кнопка «Подключить» | `/` (публичная часть) |
| `server-wizard.png` | Мастер добавления сервера (host + SSH + протоколы) | `/admin` → Серверы → добавить |
| `users.png` | Список пользователей со статусами | `/admin` → Пользователи |
| `settings.png` | Настройки: бренд, домены обхода, LAN, продвинутый X-Ray | `/admin` → Настройки |
| `bot.png` (опц.) | Меню Telegram-бота на телефоне | реальный бот |

## Кадрирование и вес

- Обрезайте по содержимому, без лишних полей браузера.
- PNG для UI, оптимизируйте (`pngquant`/`oxipng`) — цель < 300 КБ на файл.
- Для Habr — заливайте картинки в редакторе статьи (Habr хостит их сам); в тексте
  `press/habr-ru.md` пути `screenshots/...` замените на выданные Habr’ом URL.

## Обложка Habr

Готовый вектор — [`../cover.svg`](../cover.svg). Экспортируйте в PNG 1200×630 (обложка/OG):

```bash
# если установлен rsvg-convert или inkscape:
rsvg-convert -w 1200 -h 630 ../cover.svg -o ../cover.png
# или inkscape --export-type=png -w 1200 -h 630 ../cover.svg -o ../cover.png
```
