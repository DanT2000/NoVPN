# Профиль сети с «белыми списками» (для эмуляции в тестах)

Снято вживую 20.09.2026 на реальной 4G-сети оператора с включёнными белыми
списками (телефон владельца, `adb`, VPN **выключен** — замер сырой сети через
`nc`). Цель — воспроизвести такие же правила на эмуляторе/файрволе для авто-тестов
обхода, когда доступа к реальным белым спискам нет.

Диагностика приложения в этой сети: `ru=+ ext=- novpn=- → RESTRICTED`.

## Выводы (как устроен режим и как эмулировать)

1. **Порт 53 (обычный DNS) открыт полностью** — включая публичные резолверы. Именно
   поэтому обход и заводится: адрес сервера надо резолвить СИСТЕМНЫМ/провайдерским DNS
   на :53, а не через DoH. (Сделано: server-домены → `nameserver-policy` на systemDns.)
2. **DoH (:443 к 1.1.1.1 / 8.8.8.8) закрыт** — движок с дефолтным DoH-резолвером
   в такой сети «слепнет»: не может разрешить даже имя своего сервера. Это и был баг.
3. **:443 фильтруется по SNI/IP**: пропускаются только «белые» RU-домены (ya.ru, ozon,
   vk, mail.ru), а иностранные хосты и IP на :443 режутся. Даже часть RU (gosuslugi) — ⛔.
4. **Рабочие аварийные серверы пробивают НЕ через :443.** Их foreign-IP на :443
   заблокированы, но сами серверы «Обход белых списков» / «Автовыбор LTE» работали —
   значит слушают на порту, который в этой сети не режется. Для эмуляции держать это в уме:
   блок не «по IP вообще», а «по (IP:порт) + SNI на 443».

### Минимальный набор правил для эмулятора (файрвол на выход)

```
# РАЗРЕШИТЬ
allow udp/tcp dport 53 to any            # обычный DNS открыт
allow tcp dport 443 to <RU-whitelist IP/SNI: ya.ru, ozon.ru, vk.com, mail.ru>

# ЗАПРЕТИТЬ
block tcp dport 443 to 1.1.1.1, 8.8.8.8  # DoH
block tcp dport 443 to <любой foreign IP/SNI, кроме RU-whitelist>
block tcp dport 443 to gosuslugi.ru
# (порт «спасательных» серверов оставить открытым — эмулирует лазейку, через которую
#  реально пробивается аварийный VLESS)
```

Так эмулятор повторит ключевое: DoH мёртв, :443 наружу закрыт, :53 жив, а аварийный
сервер на нестандартном порту пробивается — ровно тот сценарий, что чинит наш обход.

## Как повторить замер

VPN выключить, затем из `adb shell`:
```sh
for hp in ya.ru:443 www.google.com:443 1.1.1.1:443 1.1.1.1:53 <ip>:443; do
  h=${hp%:*}; p=${hp#*:}
  timeout 4 nc -w 3 $h $p </dev/null >/dev/null 2>&1 && echo "OK $hp" || echo "BLOCK $hp"
done
```
