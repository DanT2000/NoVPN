# Панель 1.7.0: группы, «Только приложение NoVPN», доустановка компонентов

Согласовано с владельцем 10.11.2026.

## 1. Группы (вместо «категорий»)

- Группа = прежняя категория (`users.category`), плюс строка в `user_groups(name, rules)`.
  Категории без строки — группы с пустыми правилами. Ничего у людей само не меняется.
- `GroupRules` — каждое поле необязательно: нет поля → группа его не задаёт (остаётся личным).
  Поля: allowedServers, allowedProtocols, allowedProxies, priorityAccess, fullAccess, appOnly,
  deviceLimit, trafficLimitGb, resetPolicy.
- «Применить ко всем»: предпросмотр (кому что изменится, сколько конфигов снимется) →
  подтверждение → для каждого участника та же правка, что из карточки (`patchUser`):
  снятие конфигов вне разрешённого, прокси, защита.
- Новый/переведённый человек: форма (создание, карточка) подставляет правила группы при
  выборе группы. Бэкенд при создании правила сам не навязывает — решает форма.
- Отличия: `groupDiff(user, rules)` (shared) — в карточке «отличается от группы» + «Как в
  группе», на странице группы — «отличаются: N».

## 2. «Только приложение NoVPN» (`users.app_only`)

- Включено → allowedProtocols = ['xray'], allowedProxies = [] (выданные AWG/прокси снимаются).
- Подписка (/sub, /full, /server/:id/full, /backup) чужому приложению — заглушка: один
  нерабочий профиль с названием-сообщением «Подключайтесь через приложение NoVPN», Happ —
  ещё и заголовок `announce`. Наше приложение: UA `v2rayNG/1.9.5` или заголовок X-NoVPN-App.
- Кабинет: у таких людей vless-ссылки и .conf устройств не отдаются (только подписка).

## 3. Компоненты сервера

- Карточка: у каждого компонента ✓/✗ из самопроверки; у ✗ — «Доустановить».
  Прокси — переустановка прокси тем же набором (рабочие не теряются); Xray/AWG — та же
  переустановка ПО с сохранёнными ключами.
- HTTPS: причина отказа certbot (Detail) и сверка DNS домена с адресом сервера → в
  самопроверку; «домен указывает на другой адрес — подождите и нажмите ещё раз».
