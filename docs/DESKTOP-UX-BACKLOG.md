# NoVPN Desktop — разбор замечаний владельца (29.08.2026)

Список составлен по живым жалобам, а не по догадкам. Каждый пункт — с найденной
причиной, чтобы не искать заново.

## Подтверждённые дефекты (причина найдена)

### 1. «Найден браузер Яндекс», хотя его нет; вместо логотипов — буквы
`apps/desktop/src/mock/browsers.ts` — **заглушка**: Chrome, Edge и Яндекс жёстко
помечены `found: true`, Firefox `false`, независимо от того, что стоит на компьютере.
Настоящего определения нет вообще. Логотипы тоже отсутствуют — интерфейс рисует
цветной кружок с буквой.
Нужно: команда в оболочке, которая находит браузеры (реестр `StartMenuInternet`,
пути установки), и настоящие иконки браузеров.

### 2. Ссылки на расширение ведут в магазины, где его нет
Расширение не опубликовано. На `/download` и в приложении нужна инструкция ручной
установки: распаковать, `chrome://extensions`, режим разработчика, «Загрузить
распакованное». Ссылки на магазины показывать только когда там реально опубликовано.

### 3. Установщик не всегда освобождает файлы (ЧАСТИЧНО ИСПРАВЛЕНО)
`taskkill` возвращает управление раньше, чем система закрывает дескрипторы, — отсюда
«невозможно открыть файл для записи». Добавлено ожидание до 10 с, пока главный файл
не станет доступен на запись. Остаётся проверить на живом обновлении поверх
работающего приложения.

### 4. У exe пустой издатель (ИСПРАВЛЕНО)
Tauri берёт CompanyName из `authors` пакета Cargo — их не было. Добавлены. Подпись
сертификатом это не заменяет.

### 5. Иконка «дефолтная»
В файле иконка ЕСТЬ (проверено: 16-256 px, и в exe, и в установщике, и в том файле,
который раздаёт панель). Значит дело в кэше значков Windows или в карантине Defender.
Проверить у владельца отдельно, а не менять сборку вслепую.

## Маршрутизация — переделать удобство

### 6. Не предлагать то, чего нет на компьютере
«Android Studio: не найден, но включён» — в первоначальной настройке приложения,
которых нет, показывать не нужно вовсе.

### 7. Готовые значения по умолчанию
Подготовить курируемый список: Steam (и Steam Helper) — напрямую; GitHub Desktop,
Docker — напрямую (они и так работают); VS Code — сам напрямую, а его расширения-агенты
(Codex, Claude) — через VPN. Нужен разбор по процессам, а не по одному имени.

### 8. Игровые центры — добавлять папкой
При добавлении «из установленных» игра находится внутри лаунчера (Lesta Game Center).
Предлагать добавить папку целиком, а не один exe.

### 9. Управление правилами
Явные «включить/выключить» и «удалить» у каждого правила: сейчас непонятно, как убрать
случайно добавленное.

### 10. Логи для разбора
Снимать лог решений маршрутизации, чтобы можно было понять, почему конкретный сайт
пошёл не туда.

## Расширение для браузера

### 11. Связанные домены (как в Proxy Omega)
Сайт тянет ресурсы с соседних доменов, они идут мимо VPN — страница не работает.
Показывать подсказку «этот сайт запрашивает такие-то домены, добавить их тоже?» прямо
в браузере. Это снимет большую часть жалоб вида «сайт открылся, но не работает».

### 12. Правило применяется только после перезапуска
Добавил домен «напрямую» — сработало; после переключения на VPN правило требует
дополнительного запуска. Разобраться, почему нужен второй проход.

## Уведомления

### 13. Конфликт с другим VPN (СОГЛАСОВАНО, В РАБОТЕ)
Одновременно поднятые туннели (наш Meta + AmneziaVPN) забирают маршрут по умолчанию
каждый на себя — интернет пропадает совсем. Приложение обязано это замечать и
предупреждать, а не оставлять человека без сети молча.

### 14. Остаток трафика
Предупреждать в Telegram, когда у человека остаётся ~10 % лимита, с цифрами в
гигабайтах. Отдельно: при снятии по квоте человек сейчас не узнаёт причину вообще —
для AmneziaWG это выглядит как «просто перестало работать».
