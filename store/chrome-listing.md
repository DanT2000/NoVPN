# Карточка для Chrome Web Store — расширение NoVPN

Файл для загрузки: **`novpn-extension-chrome.zip`** (в этой же папке).
Это же расширение ставится в **Chrome, Edge и Яндекс.Браузер** (все на Chromium;
Edge и Яндекс умеют ставить прямо из Chrome Web Store). Firefox — отдельно (ниже).

> Публикация требует аккаунта разработчика Chrome Web Store (разовый взнос $5) и
> проходит ревью Google (обычно от нескольких часов до пары дней).

---

## Поля карточки

**Название:** NoVPN

**Краткое описание** (до 132 символов):
> Выбирайте прямо на сайте: идёт он через VPN или напрямую. Правило сразу попадает в приложение NoVPN.

**Категория:** Productivity (Продуктивность)

**Язык:** Русский

**Значок:** `extension/icons/128.png` (128×128, уже в архиве).

**Подробное описание:**
```
NoVPN — умный доступ без лишних вопросов.

Расширение работает в паре с приложением NoVPN для Windows. Прямо на открытом
сайте вы одним нажатием выбираете, как он ходит:
 • «Через VPN» — для сайтов, которым нужен доступ;
 • «Напрямую» — для всего остального, на полной скорости.

Правило мгновенно попадает в приложение и начинает действовать через пару секунд,
без переподключения. Больше не нужно открывать настройки и вписывать домены
руками — всё делается там, где вы находитесь.

ВАЖНО: расширение бесполезно само по себе — ему нужно установленное приложение
NoVPN для Windows (оно и применяет правила). Скачать: https://vpn.appswire.ru

Как это работает и почему безопасно:
Расширение не открывает никаких сетевых портов и не общается с интернетом. Оно
передаёт приложению только одно: домен текущей вкладки и ваш выбор маршрута —
через механизм «нативных сообщений» браузера напрямую в локальное приложение.
Никакие данные не собираются и никуда не отправляются.
```

**Один целевой сценарий (Single purpose):**
> Для текущего сайта выбрать маршрут (через VPN или напрямую), который применит установленное приложение NoVPN.

## Обоснование прав (Permission justifications) — это спрашивают на ревью

| Право | Зачем |
|-------|-------|
| `activeTab` | Узнать домен активной вкладки в момент, когда человек нажал кнопку в попапе. |
| `tabs` | Получить адрес текущей вкладки, чтобы составить правило для её домена. |
| `nativeMessaging` | Единственный канал к приложению NoVPN — правила применяет оно. Сетевых портов не открываем. |
| `storage` | Запоминать состояние интерфейса попапа. |

**Host permissions:** нет (никаких `<all_urls>`), только активная вкладка по нажатию.

**Использование данных (Data usage):** расширение не собирает и не передаёт данные
третьим лицам. Домен вкладки и выбор маршрута уходят только в локальное приложение
на том же компьютере. Нет удалённых серверов, нет аналитики, нет продажи данных.

**Приватность (Privacy policy):** можно указать страницу
`https://vpn.appswire.ru/privacy` с этим же текстом (Google требует ссылку, если
заявлены `tabs`/`activeTab`).

## Скриншоты (нужен минимум 1: 1280×800 или 640×400)

Проще всего снять готовый попап: загрузи расширение (Chrome → Расширения →
Загрузить распакованное → папка `extension`), открой любой сайт, нажми значок
NoVPN и сними попап с выбором «Через VPN / Напрямую». 1–2 таких скриншота хватит.

## Важно про идентификатор расширения (ID)

В `manifest.json` оставлено поле `key` — оно фиксирует ID расширения
`fcigljflnglmclncmdjmbfppppaoeech`. Приложение (нативный хост) пускает к себе
именно этот ID. **Не удаляй поле `key`** — иначе магазин выдаст другой ID, и связь
расширения с приложением оборвётся.

Если Chrome Web Store всё же присвоит другой ID (бывает), пришли его мне — я обновлю
в приложении `EXTENSION_ID` (файл `src-tauri/src/host.rs`) и в правах хоста, и
выпущу новую версию приложения.
