# NoVPN Agent

Лёгкий агент, работающий на каждом VPN-сервере. Панель (control plane) —
единственный источник команд; агент выполняет только фиксированные операции
драйверов протоколов и **не** даёт браузеру произвольный shell.

## Принципы

- **Исходящее соединение.** После установки агент сам подключается к панели
  (heartbeat + опрос заданий), поэтому работает и за NAT (домашние серверы).
- **Взаимная аутентификация.** При регистрации агент генерирует ключевую пару
  ed25519; приватный ключ не покидает сервер. Каждый запрос подписывается,
  панель проверяет публичным ключом. Общего бессрочного токена нет.
- **Идемпотентность.** Повтор задания с тем же ref не создаёт дубликат.
- **Очередь оффлайн.** Результаты, не доставленные из-за потери связи,
  сохраняются в `outbox.json` и отправляются позже.
- **Read-only аудит.** Обнаружение протоколов и импорт legacy-конфигов не
  меняют конфигурацию сервера.

## Три разных сигнала состояния

Агент и панель различают:

- **Agent connected** — агент на связи с панелью;
- **VPN service healthy** — служба (Xray/AmneziaWG) жива (`/health`, healthcheck драйверов);
- **Public endpoint reachable** — порт доступен снаружи (проверяет панель).

## Драйверы протоколов

`src/drivers/` — единый интерфейс `ProtocolDriver` (detect, healthcheck,
createAccess, importAccess, revokeAccess, getTraffic, exportConfig, …):

- **xray** — VLESS Reality (контейнер `amnezia-xray`): новый UUID на устройство,
  рабочая vless-ссылка; per-user трафик — только при включённом stats API,
  иначе «мониторинг недоступен» (не выдаёт нули за факт).
- **amneziawg** — AmneziaWG (контейнер `amnezia-awg2`): нативный `.conf`,
  трафик и last handshake из `awg show`. Официальный ключ `vpn://` пока не
  формируется — честно отдаётся `.conf`.
- **http / socks5** — администраторские прокси (заготовка драйвера).

## Переменные окружения

См. `../../.env.example` (секция `apps/agent`). Ключевые:
`CONTROL_PLANE_URL`, `AGENT_ENROLLMENT_TOKEN` (одноразовый),
`AGENT_DATA_DIR`, `XRAY_*`, `AMNEZIAWG_*`.

## Запуск (Docker)

Агент ставится через мастер добавления сервера в панели (по SSH) или вручную
одноразовой установочной командой. Локально:

```bash
CONTROL_PLANE_URL=https://vpn.dev.appswire.ru \
AGENT_ENROLLMENT_TOKEN=<из панели> \
AGENT_DATA_DIR=./data \
npm run dev --workspace apps/agent
```

Локальный health: `GET http://<host>:9090/health`.

## Что ещё предстоит

- Диспетчеризация заданий из панели (create/revoke/import) — серверная часть

- Ротация ключей агента.
- Установка proxy-сервисов (3proxy) и полноценные proxy-драйверы.
