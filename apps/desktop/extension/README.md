# Расширение NoVPN для браузера

Позволяет прямо на сайте выбрать, идёт он через VPN или напрямую. Правило
попадает в приложение и начинает действовать через пару секунд, без
переподключения.

## Как это связано с приложением

Через **нативные сообщения**, а не локальный HTTP-порт. К порту на `127.0.0.1`
может достучаться любая программа на машине; нативный хост Chrome запускает сам
и пускает к нему только те расширения, что перечислены в манифесте хоста.

```
расширение → chrome.runtime.connectNative → novpn-desktop.exe (режим хоста)
                                              ↓
                              %APPDATA%\NoVPN\browser-rules.json
                                              ↓
                      приложение опрашивает файл и применяет правила
```

Правила из браузера лежат **отдельным файлом**, а не в общем состоянии
приложения. Приложение держит состояние в памяти и периодически сохраняет — если
писать туда из другого процесса, чьи-то правки молча пропадут.

## Установка при разработке

Приложение само прописывает хост в реестр при каждом запуске (Chrome, Edge,
Яндекс.Браузер, Chromium), поэтому отдельных действий не нужно. Остаётся
загрузить само расширение:

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распакованное расширение» → выберите эту папку

Идентификатор зафиксирован открытым ключом в манифесте:

```
fcigljflnglmclncmdjmbfppppaoeech
```

Он одинаков при разработке и после публикации, поэтому манифест хоста менять не
придётся.

## Публикация

Chrome Web Store принимает **ZIP** этой папки (CRX собирает сам магазин):

```bash
cd extension && zip -r ../novpn-extension.zip . -x ".*"
```

Поле `key` из манифеста удалять не нужно — благодаря ему магазин присвоит тот же
идентификатор, что и при разработке.

## Что показывает

| | |
|---|---|
| Значок на вкладке | `VPN`, если сайт идёт через туннель |
| Окно | домен, откуда взялось правило, и два маршрута |
| Строка состояния | подключено приложение или нет |

Если приложение выключено, правило всё равно сохранится — и заработает при
следующем подключении. Об этом в окне написано прямо, чтобы человек не решил,
что нажатие пропало впустую.

## Чего нет

Firefox: у него другой формат манифеста хоста и обязательная подпись `.xpi`.
Сделаем отдельно.
