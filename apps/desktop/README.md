# NoVPN Desktop

Windows-приложение NoVPN (Tauri 2: Rust + React, движок mihomo) и расширение для
браузера (`extension/`). С 28.08.2026 живёт здесь, в монорепо панели, — раньше было
отдельной папкой `NoVPN-Plugin`. Панель и клиент общаются по версионированному
контракту: `docs/NOVPN-CLIENT-CONTRACT.md` в корне репозитория.

## Место в монорепо

- Это **отдельный пакет, не npm-workspace**: у него свои `node_modules` и `package-lock`.
  Ставить зависимости — `npm install` **внутри** `apps/desktop`. В корневой список
  workspaces он не включён намеренно: Docker-сборка панели не должна тянуть Tauri.
- Движок и драйвер адаптера в git не лежат (бинарники по 50 МБ из официальных релизов):
  `powershell -ExecutionPolicy Bypass -File scripts/fetch-engine.ps1` кладёт их в
  `src-tauri/bin/` — версии закреплены в скрипте.
- Сборка: `npm run app:build` → `src-tauri/target/release/bundle/nsis/NoVPN_<ver>_x64-setup.exe`.
- Релиз: `python scripts/package-release.py "заметки"` → подписывает Ed25519, кладёт
  `desktop/latest.json` + `desktop/novpn.exe` в корень репо и архив в `release/`.
  Приватный ключ — `d:/Project/.novpn-keys/` (вне репозитория, бэкапить).
- Канал обновлений и инструкция пользователя — `desktop/` в корне репо
  (`desktop/README.md`, `desktop/PUBLISHING.md`, `desktop/guide/`).
- Временные файлы держать в `apps/desktop/.tmp/` (в git не попадает).

# NoVPN Desktop — прототип интерфейса

Этап 1: кликабельный интерфейс на заглушечных данных. **Сетевой логики нет** —
ни Xray, ни TUN, ни Mihomo, ни сканирования установленных программ. Цель этапа —
пройтись по всем экранам и поправить UX до того, как под них ляжет реализация.

## Запуск

```bash
npm install
npm run app     # окно Tauri
npm run dev     # то же в браузере, если нужен быстрый цикл правок
```

Первая сборка Rust-части занимает несколько минут, дальше — секунды.

## Что можно пройти руками

Онбординг → первоначальная настройка → «Запустить» → маршрутизация →
переключение «Простой / Расширенный» → добавление сайта и приложения →
смена маршрута строки → выбор сервера → настройки → повтор онбординга.

**Проверка отказа:** напишите в поле подписки слово `нет` — проверка вернёт
ошибку. Так виден экран недействительной подписки, и ничего при этом не ломается.

## Стенд состояний

Девять состояний из ТЗ руками не воспроизвести — «нет интернета» по заказу не
случается. Панель открывается по **F9** или кнопкой в правом нижнем углу. Оттуда
же сбрасывается онбординг и виден макет меню в трее.

Только в режиме разработки (`import.meta.env.DEV`), в установочную сборку не идёт.

## Прямые ссылки на экраны (тоже только в разработке)

Чтобы не прокликивать путь заново при каждой правке вёрстки:

```
http://localhost:5273/?onboarded=1&conn=on
http://localhost:5273/?onboarded=1&tab=routing&rt=sites
http://localhost:5273/?onboarded=1&tab=routing&rt=lists&mode=advanced
http://localhost:5273/?step=1
```

Параметры: `onboarded`, `tab`, `rt`, `mode`, `conn`, `step`.

## Из чего собрано

| Слой | Где | Что делает |
|---|---|---|
| Токены | `src/styles/theme.css` | Перенесены из `NoVPN/apps/web` без изменений |
| Классы | `src/styles/components.css` | Оттуда же: кнопки, карточки, поля, тумблер |
| **Отклонения** | `src/styles/scale.css` | Всё, чем десктоп отличается от панели |
| Оболочка | `src/styles/app.css` | Титульная полоса, вкладки, списки, диалоги |
| Развилка | `src/styles/fork.css` | Главный визуальный элемент |
| Справочник | `src/mock/catalog.ts` | Известные сервисы: название, домен, цвет |
| Состояние | `src/state/store.tsx` | Всё в памяти, без диска и сети |
| Окно и трей | `src-tauri/src/main.rs` | Размеры, трей, закрытие в трей, выход |

Токены **скопированы, а не подключены пакетом** — проект живёт отдельно от
монорепо NoVPN. При изменении дизайн-системы в панели их надо переносить руками,
иначе продукты разъедутся. Отклонения собраны в один файл `scale.css` именно
затем, чтобы этот перенос оставался посильным.

## Решения, которые стоит знать

**Навигация — нижняя панель, четыре раздела.** «Приложения» отдельным пунктом
дублировали бы вкладку внутри маршрутизации.

**Шрифты крупнее, чем в панели.** Панель — плотный административный интерфейс,
её читают вплотную и подолгу. Десктоп открывают мельком, и увеличить его нечем.
Поэтому же в настройках есть **размер интерфейса** — замена браузерному зуму.

**Значки сервисов рисуются, а не загружаются.** Фавиконку YouTube пришлось бы
тянуть с youtube.com — то есть ровно с того сайта, который без VPN не
открывается. Значок пропадал бы именно тогда, когда он нужен. Цвет и буква
зашиты в `catalog.ts` и работают офлайн.

**Кнопка в титульной полосе одна.** «Развернуть» убрана: окно ограничено по
размеру, и разворот визуально ничего не делал. «Свернуть» и «Закрыть» означали
одно и то же, потому что крестик и так прячет в трей. Выход — правой кнопкой по
титульной полосе или через меню в трее.

**Иконка — буква N на синей плитке.** Логотип целиком в трее превращается в
пятно; одна буква читается на 16 px. Проверено на 16 / 24 / 32.

**«Отключить» красная.** Это действие, обрывающее защиту.

**Окно 480×820**, от 440×700 до 680×1150.

## Чего ещё нет

**Светлая тема.** Переключатель на месте и честно предупреждает. Тема потребует
второго набора значений для всех токенов — работа отдельного захода.

**Системные окна выбора файла и папки.** В диалоге добавления приложения эти два
источника показывают, что произойдёт, и дают пример — но подставлять фальшивый
список файлов было бы обманом: человек решил бы, что функция работает.

**Разрешение конфликтов** между своими правилами и готовыми списками: раздел
«Исключения» в расширенном режиме пока пустой.
